## 1. 검증 환경과 실행 범위

- macOS 15.1.1 arm64, Homebrew OpenJDK 25.0.5.0.3, Maven 3.10.0, Apache Tomcat 11.0.27, Google Chrome.
- 백엔드: `http://127.0.0.1:8080/enjoytrip/api`. 프론트: 설치된 VS Code Live Server 5.7.10 엔진을 `Frontend` 루트·127.0.0.1:5500으로 실행.
- 현재 Tomcat의 배포 클래스 36개와 새로 빌드한 WAR의 클래스가 모두 일치했다. 검증을 위해 기존 Tomcat을 재시작하거나 기존 계정을 초기화하지 않았다.
- 검사용 임시 계정·게시글은 검사 후 정리했고 게시판 잔여 글은 0건임을 확인했다. 검증용 Live Server는 검사 후 종료했다.
- STS 설치 플러그인의 Tomcat 11·Web Facet 6.1·m2e-wtp 지원은 파일로 확인했다. STS의 Run on Server 화면 조작·실제 IDE 배포와 Windows 실환경 실행은 검증하지 않았다.

## 5. 응답성·설정 확인

게시판 목록을 로컬에서 순차로 20회 읽은 결과: **중앙값 0.66ms, P95 1.44ms, 최대 21.34ms**. 빈 게시판의 loopback 요청을 측정한 값이며 부하 검사·운영 성능 보증은 아니다. 위 관광 조회는 실제 외부 API와 화면 갱신 시간을 함께 측정했다.

최종 점검에서 Web Facet이 6.0이고 `web.xml`·Servlet 의존성은 6.1인 불일치를 발견했다. 설치된 STS의 `org.eclipse.jst.j2ee.web` 플러그인이 Web Facet 6.1을 선언하고 Tomcat 어댑터가 이를 지원함을 확인한 뒤 **Web Facet을 6.1로 정렬**했다. XML 검증으로 Web Facet·web.xml 버전 일치를 확인했고 README도 갱신했다. 이 메타데이터 수정은 Java 클래스와 WAR 실행 동작을 변경하지 않는다.

## 6. 남은 확인·제출 항목

- **JSP 활용 여부 확인 완료 — 미사용**: 소스·웹 리소스와 빌드된 WAR에 JSP·JSPX·JSPF·태그 파일이 모두 0개다. `ApiController.service()`는 JSON을 반환하고 `HomeController.doGet()`은 `/pages/map.html`로 리다이렉트하며, JSP forward/include 경로가 없다. pom.xml에는 JSP API·JSTL 의존성만 선언되어 있다. 현재 Servlet + HTML/JSON 구조에서는 JSP 활용 부분이 구현되지 않았으므로 목표 항목은 미체크로 남긴다.
- **STS 실제 배포**: README 절차대로 IDE에서 Run on Server를 실행한 검증은 남아 있다.
- **사용성 평가**: 사전지식이 없는 실제 사용자를 대상으로 한 평가는 수행하지 않았다. 키보드·입력 오류·재시도 동작 확인과 구분한다.
- **범위 밖 검증**: 실제 모바일 기기·여러 OS/브라우저, 실제 위치 기반 내 주변 검색, 부하·성능 SLA는 검증하지 않았다.
- **최종 제출**: GitLab 업로드·반별 제출과 최종 Git 반영은 수행하지 않았다. 현재 연결된 원격 저장소는 GitHub다.
